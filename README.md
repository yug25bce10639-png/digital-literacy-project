# Digital Literacy Project 
  
## About the Project
This repository contains all the tasks completed as part of the Digital Literacy course. The project focuses on developing digital skills such as infographic creation, professional portfolio building, coding practice, email etiquette, and cybercrime awareness.

## Tasks Included
- Task 1 – Infographic on Digital Literacy
- Task 2 – Digital Portfolio (GitHub, LinkedIn, Kaggle)
- Task 3 – HackerRank Problem & Google Form
- Task 4 – Email Etiquette & Social Media Rules
- Task 5 – Cybercrime Case Study & Prevention Checklist
